An archive of https://koreankite.tistory.com, an incredible comprehensive documentation of Korean kite making and materials science, including bamboo spar harvesting/shaping, hanji stretching, and records of many kite making innovators of the past 50 years. This site is now offline, but seems to have been connected with the Korean Kite Association which had been based in Bukchon hanok village.
